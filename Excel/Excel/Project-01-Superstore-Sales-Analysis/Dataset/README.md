# Superstore Sales Analysis – EXCEL---

## Project Overview

This project focuses on analyzing Superstore sales data using Microsoft Excel to identify sales trends, product performance, customer purchasing patterns and regional performance.
The objective is to transform raw sales data into meaningful business insights through data cleaning, analysis and interactive dashboard development.

## Business Objectives

- Analyze overall sales performance.
- Identify monthly sales trends.
- Evaluate product and category performance.
- Analyze quantity sold across different products.
- Identify high-performing regions.
- Understand customer purchasing patterns.
- Develop an interactive dashboard for business reporting.

## Tools and Technologies

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Formulas
- Conditional Formatting
- Data Visualization

## Project Workflow

1. Raw Data Collection
2. Data Inspection
3. Data Cleaning and Preparation
4. Data Analysis
5. KPI Development
6. PivotTable Creation
7. Dashboard Development
8. Business Insights

- Total Sales
-Total Profit
-Total Orders
-Total Customers
-Total Quantity
-Profit Margin %
-Average Order Value
-Average Profit per Order
